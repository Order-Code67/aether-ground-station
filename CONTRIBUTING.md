# Участие в разработке

## Ветки

- `main` — стабильная линия релиза.
- Feature-ветки: `feature/<short-name>` или `cursor/<topic>`.

## Перед PR

```bash
npm install
npm run typecheck
npm run test:critical
```

Для нативных изменений дополнительно:

```bash
cd src-tauri && cargo check
```

## Правила

1. Не добавлять mock-устройства, фиктивное видео или подставную телеметрию.
2. Новое железо — через адаптер + Device Manager, не напрямую в UI.
3. Не логировать пароли, токены, ключи.
4. Remote-изменения не должны открывать канал пилотирования / боевые команды.
5. Документировать публичные контракты адаптеров в `docs/`.

## Коммиты

Кратко по смыслу (why), на английском или русском, единообразно в рамках PR.
