# Безопасность

## Сообщить об уязвимости

Откройте **private** security advisory или свяжитесь с maintainers через GitHub, не публикуя эксплуатацию в Issues.

## Локальная станция

- Учётки и роли хранятся локально (SQLite, hash пароля).
- Смените пароль `admin` сразу после установки.
- COM / USB / сеть не сканируются без согласия оператора.

## Remote

- TLS / VPN / сессии / audit — в зоне Remote Gateway.
- Через remote **не** передаются команды полёта, наведения и боевые функции.
- Sandbox / stub не выдают синтетические станции за «живые» без флага `synthetic`.

## Секреты

Не коммитить `.env`, ключи подписи NSIS, токены обновлений.
